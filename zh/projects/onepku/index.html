OnePKU

GitHub ↗

起因

一开始是想做一个北大版的 oneTHU，把学校各个网站的东西放进一个应用里。做的过程中发现北大不少网站其实不太统一，想全做齐挺难的，所以就挑了几个我自己用得上的功能做了出来。

能做什么

  • 看回放：边下边播，可以倍速、接着上次看，缓存下来之后没网也能看，还能在本机生成字幕。
  • 存课件：课件和回放按学期、课程存到一个文件夹里，不用再去每门课的页面里翻。
  • 作业和成绩：各门课的作业放在一个列表里，成绩和 GPA 也能看。
  • 还有通知、校历、校园卡和空闲教室这些。

怎么做的

用 Tauri 做的桌面应用，核心逻辑用 Rust 写，界面是 React。访问学校服务的部分用了同学开源的 PKU CLI。登录是扫码或者短信，不存密码。MIT 协议开源。

之后

功能基本就这些，之后有比较多人需要的再加。用的人主要是我自己。
