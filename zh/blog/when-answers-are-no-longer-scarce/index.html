当答案不再稀缺，我们还想要什么？

如果 Agent 能解决几乎所有说得清楚的问题，难的就会变成想要什么。这是我围绕这件事想到的几个念头，中间有一次和我爸在江边散步时的争论。

我最近常想一个问题：如果有一天 Agent 强到能比普通人更快、更便宜、更靠谱地解决几乎所有说得清楚的问题，人的生活会变成什么样？

这里的「说得清楚」范围可以很大。比如我跟 Agent 说，我想写篇文章，但还不知道想写什么，只有几个模糊的感觉。然后我们开始聊，我说一个念头，它帮我展开，展开的东西又引出新的问题，我们接着往下聊。几个小时以后，一开始说不清的东西就有了形状。这种事现在已经能做到一些了。如果它继续变强，工作、研究、工程、管理，甚至很大一部分思考，都会被算进「说得清楚的问题」里。

下面是我围绕这个想到的几件事，彼此有联系，但不是一条完整的论证。

每个人都有一支自己的团队

以前一个人的能力，差不多就是他自己学会了多少。数学、工程、设计、编程，每样都要学好几年，会的人少，也就值钱。

如果以后每个人都有一个了解自己的助手，背后能调几百上千个专门的 Agent，那一个人能做到的事，就不太取决于他自己会什么了。想做游戏，就去找写程序、画画、做音乐、写剧本、测试的 Agent；想研究一种病，就有 Agent 帮着读论文、设计实验、跑模拟、分析数据。

我觉得这其实是在给人更多的自由。人一直在被环境影响，家、学校、朋友、这个时代。我在意的是一个人还有多少种变成别的样子的可能，能不能换方向，能不能重来。Agent 让这些可能多了很多。

那时候难的是想要什么

但如果有一天你跟这个助手说，最近总觉得生活有点无聊，又说不上为什么，这反而可能是最难办的问题。

过去难的是怎么把事情做到。以后做到变容易了，难的就变成到底什么问题值得问，你自己到底想要什么。

所以我觉得 AI 以后很重要的一个方向，说白了就是更懂人。现在大家看 AI，看的是题有没有做对、代码能不能跑、跑分涨了多少。但一个已经很会解决问题的系统，接下来得知道什么问题值得解决，这就要懂具体的人：分得清一个人嘴上说的和真正想要的，分得清一时的刺激和长久的满足，知道什么时候帮他实现，什么时候提醒他这个未必会让他开心。光会做事不懂人，它就只是一个优化器，而优化什么才是最要紧的。

算力会变成一种预算

如果大部分脑力活都能交给计算，算力就会变成直接用来做事的资源。每个人有一份，家庭、公司、城市、国家也各有一份。那这些算力拿去做什么？

现在一个人有了钱，会想是买房、旅行、创业还是投资。以后可能会想，拿一部分算力做一个自己的游戏世界，研究爸妈身上的某种病，或者投给延长寿命的公共项目。也可以拿去拍一部只给几个朋友看的电影，或者研究一个没什么人认真研究过的数学问题，就因为觉得它好看。一群人也可以凑起来，决定一起造一艘飞船。

做事变便宜以后，能实现的愿望会多很多。算力投到哪，某种程度上就说明了用它的人想要什么样的世界。

我爸说人是贪婪的

这些我经常跟我爸聊。有一次我们在江边散步，又聊到这个。他的看法很直接：人是贪婪的，东西再多，也还是会比较、会争、会嫉妒、会想要权力，只要这些还在，技术乌托邦就不会来。

我也不是完全不同意。但我怀疑，我们今天看到的人性，有多少是一直都这样，有多少是在东西不够的环境里养出来的。

一个人从小就被告知，好学校、好工作、房子、医疗、钱、位置都是有限的，别人拿到了自己就少一份，那竞争自然会渗进生活的方方面面。然后我们看着这样长大的人，很容易说一句：人本来就是这样。

可如果吃的、住的、教育、医疗和大部分东西都不再是压力，很强的 Agent 也不只是少数人才有；如果普通人也能轻松做出以前只有大公司才做得出的东西，很多「别人有所以我没有」的关系慢慢没了，那时候的人会变成什么样，我们真的知道吗？

我不知道。但我不太相信今天的社会就是人性最后的样子。一个长期很富足、几乎没有生存压力、又有很大创造能力的文明会养出什么样的人，我们还从来没见过。

活得更久

这件事我在《我为什么想活下去》里写过，这里只说一点：如果人能活几百年，人生的节奏会完全不一样。现在读书、工作、买房、成家、退休都挤在几十年里，所以很多事都急，早年选错了代价很大。如果能活几百年，二十岁选错方向，四十岁重新学物理，八十岁换个国家住五十年，都不算晚。很多现在觉得来不及的事，又都能选了。

把世界变大

跟宇宙比，地球很小。我们花那么多力气去争一块地、一套房、一个位置，很大程度上是因为现在能用的世界就这么大。地球外面有多得没法想象的物质、能源和空间。

如果有了很强的 AI、自动化的工业，人又活得很久，星辰大海就慢慢变成能做的事了。机器和工厂先去，Agent 帮着设计能源、生命维持、材料和飞船；要做几十年、几百年的工程，对活得很久的人来说也没那么远。先是月球、火星、小行星，再往外。

愿望多到地球装不下的时候，除了在原来的地方接着抢，还可以把世界变大。

不只一个世界

愿望也不一定都得放在现实里。现在做一个大型开放世界游戏，要几百上千人做好几年。以后也许只要跟 Agent 描述：这里有两个月亮，人住在很大的浮岛上，每个人生下来会一种不同的魔法，这个世界有几千年的历史，里面的人都记得事情，我想在里面生活十年。它生成的就是一个一直在变、能进去生活、有自己规则和历史的世界。

有人想要很真实的历史模拟，有人喜欢奇幻和打仗，有人就想安静地种地。到那时候，「体验」可能会是最大的产业，甚至都不太能叫产业了。

工作没了以后

很多人担心，AI 把活都干了，人还有什么意义。我有时候觉得这个担心本身带着工业时代的习惯，好像人的价值必须靠他能给生产贡献什么来证明。

小孩搭积木不产生 GDP，一个人花三年研究自己喜欢的一段历史，也未必有经济价值。和朋友打游戏、旅行、谈恋爱、做音乐、养花，这些事不用先算成工作才有理由存在。

以后人可能终于有条件去做那些以前因为不赚钱、没时间、没用而放下的事，工作也可能变成一种自己选择参加的游戏。有人想建城市、去火星，有人喜欢经营公司、研究数学，也有人还是喜欢自己写代码，哪怕 Agent 一秒钟就写得比他好。汽车出来以后大家还在跑步，有了计算器也还有人喜欢心算。人做事也不全是为了结果。

最后剩下的问题

所以到那时候，人要学的东西也会变。现在我们花二十年教一个孩子，很多时间是在教他怎么成为一个有用的人。以后可能要花更多力气，帮他成为一个知道自己想要什么的人：分得清快乐和刺激，会跟人相处，面对几乎无限的选择，能找到一个值得花十年去弄的问题。

Agent 能帮人解方程，但很难替他决定为什么在意这个方程；能帮人建一座城，但为什么建、给谁建、里面的人怎么生活，还是要人自己回答。

我不知道这样的未来会不会来。技术不会自己变出乌托邦，新的权力、稀缺和冲突还会有，人也不会突然都变成好人。但我也不太接受另一种说法：因为今天的人贪婪、嫉妒、爱争，以后也只能这样。

我最希望的是，以后的小孩从小就知道，只要一件事物理上做得到，身边就有一群 Agent 能帮他做到。那他抬头看天的时候，问的可能就不只是「我以后该找什么工作」，还会问「这辈子我想去哪」「我想造点什么」「我想看到什么样的世界」。
