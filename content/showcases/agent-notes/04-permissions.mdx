# Agent 到底有多大权限

> 权限不属于大模型

前面已经讲过，大模型负责选择，软件负责执行。

因此，Agent 的行动权限来自它能够调用的全部工具。

## 每个工具带来一种能力

例如，一个整理文件的 Agent 可能有这些工具：

- “查看文件夹”让它知道里面有什么；
- “阅读文件”让它看到文件内容；
- “移动文件”让它改变文件的位置；
- “删除文件”让它把文件删掉；
- “发送消息”让它把内容发给别人。

没有“删除文件”工具，无论大模型多么想删，它都做不到。每添加一个工具，就是给 Agent 增加一种能力。

## 工具还会组合

如果 Agent 只能阅读私人文件，却不能对外发送任何内容，私人文件不会因此离开电脑。

如果再给它一个“发送消息”工具，情况就改变了：

> 阅读私人文件 + 向外发送消息
> = 可以把私人文件发出去

这个结果不属于某一个工具，而是几个工具连起来以后出现的。

所以，Agent 的实际权限，是所有工具在当前范围内，组合起来能够造成的后果。

## 它能看见什么

权限不只是“能做什么”，还包括“能看见什么”。

如果把家庭住址、银行账号或者私人日记放进上下文，Agent 就已经获得了这些信息。即使它没有修改任何东西，能够阅读本身也是一种权限。

因此，一个 Agent 的权限由两部分组成：

- 它能够看见的内容；
- 它能够通过工具造成的后果。

## 沙箱、授权和人工确认

**沙箱**是给工具画出一个范围。文件工具可以在沙箱里活动，却碰不到外面的文件。

**授权**是决定工具可以使用谁的身份，访问哪些东西。

**人工确认**则是在工具真正执行之前加一道门。大模型可以选择“转账”，但只有人点击同意以后，软件才会真正执行。

这些东西没有让大模型变得更聪明。它们只是在决定：即使 Agent 作出了某个选择，这个选择最终能不能变成现实。
