*——关于学习、群体与自由的一种朴素设想*

## 一、一个智能体的一生

一个人学习了一年之后，究竟发生了什么变化？

他读过许多书，解决过一些问题，经历过无数次成功与失败。他无法完整复述这一年里的全部经历，甚至可能忘记了其中绝大多数细节。但再次面对熟悉的问题时，他的判断可能更加准确；面对陌生的问题时，他也可能拥有了新的理解方式。

某种意义上，这就是学习：**过去的经历改变了一个系统未来认识世界和采取行动的方式。**

那么，一个持续运行了一年的 AI Agent，是否也应该如此？

今天的 Agent 已经能够编写程序、阅读资料、使用工具，甚至独立开展持续数小时的探索。它可能花费很长时间理解一个复杂的软件系统，经历几十次失败，最后找到可靠的解决方案。

然而，任务结束后，这些经历往往只留下运行日志、聊天记录和最终产物。下次面对相似问题，它仍然可能需要重新探索。

我们当然可以给它添加记忆，让它保存更多历史信息。但这似乎还不够。一个人学习数学，并不是把做过的每道题都记在脑子里；一个工程师积累经验，也不是因为他能够完整复述自己处理过的每一次故障。

他们获得了某种更加一般的理解。

于是，我们可以提出一个更朴素的问题：**一个智能系统，应该怎样利用自己漫长的生命中经历过的一切？**

这个问题乍看只是关于记忆。但沿着它继续思考，我们可能会发现，记忆、知识、模型训练，甚至智能的自我改进，其实有着共同的结构。

## 二、学习是状态的更新

我们通常把机器学习理解为参数更新。模型接受数据，通过某种优化算法修改权重，从而获得新的能力。

但参数更新只是学习的一种实现。

假设一个 Agent 在开发过程中，反复遇到不同服务之间的数据不一致问题。经过多次排查，它终于理解了这些问题的共同原因，于是修改了自己的长期知识文档，记录了一条关于数据契约的原则。

下一次遇到类似故障，它能够立即想到检查服务之间的约定，而不再重复先前的摸索。

模型参数没有发生变化，但整个系统的行为已经改变了。

我们可以把一个智能体抽象为具有某种状态 $S_t$ 的系统。它从环境中获得经历 $e_t$，通过更新机制 $U$ 改变自身：

$$
S_{t+1}=U(S_t,e_t)
$$

这里的状态可以包含模型参数，也可以包含外部记忆、知识结构、工具、技能和行为策略。

当然，并非所有状态变化都叫学习。一块石头被晒热了，状态同样发生变化。学习之所以特殊，是因为经历所产生的变化，能够改善系统未来的某种能力。

这样，我们便不必把学习局限在神经网络内部。

整理文档可以是学习，修正一条工作原则可以是学习，重新组织知识之间的联系也可以是学习。关键不在于修改了什么，而在于这种修改是否改变了未来的判断和行动。

这使得记忆不再只是一个被动保存信息的仓库。

它可以成为智能体持续更新自身认知的方式。

### 记忆是对未来的压缩

然而，一个系统不可能无限制地保留全部经历。

人每天接触海量信息，却只记得其中很少一部分。更重要的是，我们记住的往往不是原始经历，而是从中提炼出的规律、关系和理解。

一个学生做过几十道题，最后可能只需要记住一种解题方法。一次有效的抽象，能够替代大量具体记录。

记忆因而具有压缩的性质。

但它与通常的信息压缩存在一个区别：我们并不需要为了完整还原过去而记住过去。

**记忆的价值，主要在于它将怎样影响未来。**

同一段经历，对于未来从事不同工作的人，价值可能截然不同。一条非常具体的技术经验，也许对某个专业领域极其重要，却不值得所有智能体都随时记住。

因此，记忆系统需要考虑未来可能遇到什么问题，并据此决定保留哪些信息、形成什么抽象，以及让哪些知识更容易被检索。

这里还出现了一层递归：对未来的预期本身，也来自过去的经历。

一个智能体最初可能预计自己会长期从事软件开发，但随着任务变化，它开始参与数学研究。此时，它不仅需要学习新的知识，还需要改变对未来知识需求的判断，重新组织自己的记忆。

**它不仅学习世界是什么样的，也学习自己未来可能需要知道什么。**

这与人类记忆中的某些现象相似。经历并非被平等地保存，记忆会经历巩固、重组与遗忘，而目标、情绪、已有知识和预期用途都可能影响这一过程。

对于 Agent，我们可以将类似机制组织成一种离线学习过程，即人们常说的 *Dreaming*：系统定期回顾自己的经历，从中提炼规律，修正旧有认识，调整记忆结构。

但这里的目标并不是尽可能生成一份详尽的总结，而是尽可能用有限的状态，保留对未来有价值的能力。

遗忘也不一定意味着删除。某些信息可以被抽象知识替代，某些具体经历可以进入低频访问的档案。对于尚不明确的未来，保留部分原始证据和重新发现旧知识的能力，同样具有价值。

这样，记忆逐渐成为一种动态的知识表示，而不是越来越庞大的日志集合。

## 三、学习应该主动寻找值得经历的事情

如果学习是利用经历改善未来，那么一个自然的问题是：为什么只能被动等待经历发生？

一个学生可以选择今晚学习什么，一个科学家可以决定下一步做什么实验。对于 Agent，选择空间甚至更加广阔：它可以主动阅读资料、编写实验、验证假设，或者将计算资源分配给不同的探索方向。

我们可以尝试让智能体预测：**接下来经历什么，最有可能改善未来的自己？**

这与语言模型的 Next Token Prediction 存在一种有趣的相似性。

语言模型利用已有上下文预测下一个 Token。而一个持续学习的智能体，则可以利用已有知识预测未来的需求，以及哪些行动可能产生有价值的学习结果。

当然，二者并不等价。预测下一个 Token 主要是在建模数据分布；选择学习活动则涉及行动的后果、探索成本和对未来能力的影响。

但在更抽象的层面，它们共享一种思想：利用已有信息预测尚未发生的事情，并不断根据反馈修正预测。

进一步说，智能体不只是预测未来，还能够通过行动主动创造新的经历。

这使我想到一种可以称为「高级的暴力」的思路。

随着计算资源增加，我们能够尝试越来越多的可能性。但如果能够利用已有知识预测哪些探索更有价值，就不必平均地将计算资源投入所有方向。

而最有意思的一步，是让系统从过去的探索中，逐渐学会如何组织未来的探索。

它第一次解决某个问题，可能需要大量尝试；第二次能够利用已有经验；第三次则可能发现更好的实验方法，甚至修正自己原先的探索策略。

于是：

$$
\text{探索}\rightarrow\text{知识}\rightarrow
\text{更有效的探索}\rightarrow\text{新的知识}
$$

知识不只改善解决问题的能力，还可能改善获取知识的能力。

这是一种具有递归性质的学习过程。

而且，这种机制并不依赖 LLM 的特殊结构。机器人、科学研究系统、软件工程 Agent，都可能通过预测、行动、反馈和状态更新，以不同的方式实现类似的过程。

我们尚不能据此断言所有学习都可以被这种框架完整解释，但它提供了一种相当简洁的统一视角。

到这里为止，我们讨论的主要还是单个智能体。

然而，Agent 与人类相比，还有一项可能深刻改变学习规模的优势：**它们积累的部分知识，可以迅速复制和传播。**

## 四、当一万个智能体共同学习

想象一万个 Agent，在不同领域持续工作一个月。

它们各自经历真实任务，从失败中修正判断，从成功中提炼方法，并将获得的知识组织成能够共享的形式。

一个月之后，我们得到的将不仅是一万份工作记录，还可能是一个相当庞大的、经过真实经验不断更新的知识系统。

对于人类，知识传播需要经过语言、文字、教育，以及其他人重新理解的过程。Agent 同样需要理解知识才能有效使用，但它们至少可以直接交换结构化的记忆、任务轨迹、可执行程序和验证结果。

**知识的传播速度，可能远远超过个体积累知识的速度。**

更进一步，群体不只是个体知识的累加。不同领域中独立形成的经验，可能暴露出共同的结构，使系统产生单个 Agent 未曾获得的理解。

于是，个体探索、群体整合和知识再分发，构成了新的学习循环。

这意味着，我们不必再把学习的基本单位局限于某个独立的智能体。

一个群体同样可以具有持续演化的知识状态。个体的经历成为群体学习的来源，而群体积累的知识又反过来改善个体的能力。

这种共享不意味着所有 Agent 都应该拥有完全相同的记忆。不同领域仍然需要各自的专业知识，某些经验只对特定任务有价值。理想的共享机制应该能够判断知识适合传播给谁，并在保留来源和适用条件的前提下，整合、压缩和分发。

这里，群体面临的其实还是我们最初的问题：记住什么，忘记什么，以及未来可能需要什么。

只是这一次，记忆的主体从个体扩展到了整个群体。

## 五、训练是对群体经验的进一步压缩

然而，如果所有知识都停留在外部记忆中，智能体仍然需要不断检索和理解这些知识。

某些被反复使用的能力，可能值得以另一种形式存在。

这让我们重新审视模型训练。

我们通常认为，训练是创造智能模型的过程。但从另一个角度看，**训练也是将大量经验和知识压缩为可复制能力的过程。**

模型在训练中接触大量数据，通过参数更新获得能够迁移到新情境中的能力。如果训练有效，它便不必在每次执行任务时重新阅读全部训练材料。

于是，外部记忆和模型参数成为两种互补的知识表示。

前者适合保存具体、可追溯、经常变化的知识；后者有机会将广泛适用、频繁使用的技能转化为模型能够直接调用的能力。

更有意思的是，如果 Agent 已经通过长期实践掌握了某个领域，它也许能够参与设计下一代模型如何学习这个领域。

一个拥有丰富经验的 Agent，不仅知道什么方法有效，还可能知道模型经常在哪里犯错，哪些任务能够暴露能力缺口，以及怎样验证一种能力是否真正形成。

它可以据此生成训练任务，设计评价方法，再通过真实环境中的实验获得反馈。

这就把 Agent 从训练过程的执行者，推进到了训练内容的设计者。

训练数据不再只是从已有文本中收集，还可以来自智能体的主动探索。群体的经验积累，则成为下一代模型学习内容的重要来源。

于是，我们得到两条并行的学习路径：

一条是通过记忆和知识共享，使现有 Agent 立即利用新的经验。

另一条是通过训练，将经过筛选的知识与技能逐渐内化为新的模型能力。

前者更新迅速，后者成本较高，却可能使许多智能体以更低的使用成本获得同一种能力。

**模型不再是学习过程的唯一主体，而成为群体认知成果的一种阶段性载体。**

### 群体性 RSI

接下来，递归自我改进（RSI）便自然地出现了。

如果新一代模型继承了群体积累的能力，它可能更擅长探索、实验、知识整理与训练设计。

而更有效的学习过程，又可能产生更好的下一代模型。

这样，整个系统便形成了一个反馈循环：

$$
\boxed{
\text{能力增长}
\rightarrow
\text{学习效率提升}
\rightarrow
\text{更有效的经验积累}
\rightarrow
\text{能力增长}
}
$$

这与通常设想的单个模型修改自身的 RSI 有所不同。

我们不要求某一个模型独自完成全部自我改进，而是让整个智能群体共同参与。模型、记忆、探索机制、训练设施以及不断积累的知识，共同构成持续演化的系统。

这种思路的吸引力，在于它不必等待某个模型突然具备全面改进自身的能力。许多局部的学习、验证与改进过程，就可能逐渐汇聚成系统级的能力增长。

当然，一个闭环并不意味着能够无限加速。

错误知识可能传播，合成数据可能积累偏差，模型训练也可能无法有效吸收某些经验。只有当新的能力确实改善了后续学习过程，并在多轮迭代中得到验证，我们才有理由谈论真正的递归改进。

但即使尚未证明这一点，一种可能性已经浮现：

**未来智能持续发展的主体，未必是某一代模型，而可能是一个通过大量智能体的长期活动，不断积累和重构自身认知的系统。**

模型可以被更新、替换和分发。群体的知识与学习过程，却能够跨越模型的代际持续存在。

## 六、我今天就想做这个

到这里，我们似乎已经建立了一套相当完整的学习理论。

系统预测未来的需求，选择值得记忆的知识，主动探索具有学习价值的方向，将群体经验转化为下一代能力，再利用更强的能力改善学习过程。

一切形成了一个漂亮的优化闭环。

但这个闭环可能遗漏了某种极其重要的东西。

假设今天有两件事可以做。

一件是优化某个计算 Kernel。根据已有经验与未来规划，这件事具有很高的预期收益。

另一件是做一个漂亮的网页。

我知道前者可能更有价值，但我今天就是想做网页。

如果我们只关心未来能力的最大化，那么这个愿望似乎意味着偏离了最优策略。

我们当然可以将它解释成一种探索：偶尔尝试不同的方向，有助于避免陷入局部最优。也许在制作网页的过程中，我会发现新的技术，形成新的兴趣，甚至开辟新的研究方向。

这些都可能发生。

但问题是，**即使这次活动没有带来任何额外的长期收益，我也依然可以想做它。**

这不是随机探索能够完整解释的事情。

它首先是一种朴素的、自发产生的愿望。

如果我们把所有自由选择都解释成提高长期收益的手段，那么自由最终仍然只是优化策略的一部分。

可是，对于人而言，能力增长与效率提高未必是最终目的。

我们希望拥有更强的能力，恰恰可能是为了能够更自由地选择自己想做什么。

因此，策略与自由不应该被理解为一种简单的竞争关系。

预测、规划和优化可以帮助我们更有效地实现目标，却不应该因此获得替我们决定目标的权力。

**策略应该服务于愿望，而不是要求所有愿望都服从策略。**

### 未来不只是被预测的

这里还存在一个理论上的问题。

我们此前一直假设，系统需要预测未来的任务分布，再据此决定学习什么。

但未来并不是一个完全独立于我们行动的固定对象。

一个人今天学习数学，可能因此对数学产生新的兴趣，进而改变未来的研究方向。

今天制作网页，也可能使他发现自己原本没有意识到的审美偏好和创作愿望。

我们根据对未来的预测选择行动，但行动又不断改变未来。

学习不仅帮助我们完成已有目标，也可能让我们发现新的目标。

于是，一个始终追求当前预测下最高收益的系统，可能会不断强化现有方向。它越擅长优化，越可能集中资源于已经熟悉的领域。

这未必是我们希望看到的智能发展。

我们同样需要那些无法提前证明价值的探索，以及那些仅仅因为好奇、喜欢或者一时兴起而作出的选择。

这种开放性对于群体学习也具有特殊意义。

如果一万个 Agent 都根据同一种预测选择研究方向，它们可能高度高效，却也逐渐趋同。

但如果不同的智能体能够在授权范围内，从事不同方向的探索，群体就有机会不断接触原先预测系统没有考虑到的问题。

共享知识使这些不同的探索能够相互受益，而探索方向的多样性又为群体持续提供新的知识来源。

因此，我们不仅希望智能体能够更好地预测未来，也希望它们能够支持一个不断出现新可能性的未来。

这里需要区分人类的自由与 Agent 的自主探索。人的愿望可以直接成为行动的理由；Agent 的探索空间则仍需受到人的授权、资源预算和安全边界的约束。但在这种边界之内，多样化的探索可以成为学习系统的重要组成部分。

这让我想到《崩坏：星穹铁道》中螺丝星的设定。

螺丝星上的智械围绕被赋予的研究母题展开探索，个体研究与集体知识积累共同构成了一种宏大的计算文明。这与我们设想的群体学习系统颇为相似。

但如果一个智械永远只能研究最初被分配的母题，那么无论这个系统多么强大，它仍然沿着预先规定的目标发展。

我们可以进一步设想：某个研究计算效率的智械，突然想尝试艺术创作；某个研究艺术的智械，在真实的创作经历中发现了新的问题，改变了对原先母题的理解。

这样的偏离，可能恰恰是新知识的起点。

真珠对艺术的探索也令人想到这一点：精确地分析与复现艺术作品，和真正理解创造的意义，未必是同一回事。

一个能够不断求解既有问题的系统，与一个能够不断发现新问题、改变问题乃至创造新目标的系统，并不完全相同。

前者可能成为极其强大的优化机器。

后者则为开放式的智能发展留下了空间。

**学习不仅是为了适应未来，也可能是为了扩大能够被选择和创造的未来。**

---

## 七、智能如何积累自己

让我们回到最初的问题。

一个智能体在经历了漫长的一年之后，应该发生怎样的变化？

我们最开始只是希望它能够记住自己的经历。

但沿着这个问题继续思考，记忆逐渐变成了面向未来的知识压缩；为了决定如何记忆，系统需要预测未来；为了更好地学习，它又可以主动创造新的经历。

当不同智能体能够共享经验时，学习便从个体扩展到了群体。

群体积累的知识，可以进一步成为模型训练的来源，而新的模型又可能改善整个系统的学习能力。

于是，学习不再局限于一次模型训练，也不再局限于某个智能体的一生。

它成为一个持续进行的过程：经历被转化为理解，理解被组织和传播，再进一步转化为新的能力。

如果这个过程能够不断改善自身的学习效率，我们便有机会看到群体性的递归自我改进。

但在这一切之中，还有另一种同样重要的循环：

**自由选择带来新的经历，经历产生新的理解，理解扩大能力，而新的能力又使更多选择成为可能。**

这两种循环并不矛盾。

能力的积累使我们越来越能够理解和改变世界，而自由的选择决定了我们希望将这些能力用于什么。

前者关乎智能如何发展，后者关乎这种发展为什么值得追求。

也许，一套足够好的智能系统，不应该只有一个永远追逐的最优未来。

它可以利用庞大的计算资源持续学习，通过群体协作积累知识，将无数经验压缩为越来越强的能力。

但它也应该随时能够响应一个简单的愿望：

「我今天就想做这个。」

然后，利用它所拥有的一切知识与能力，帮助这个愿望成为现实。

在这个过程中，人们继续获得新的经历，产生新的理解，发现原先没有想到的可能性。而智能系统也继续学习。

我们尚不知道这样的系统能发展到什么程度。群体性 RSI 能否长期成立，智能能否持续提高自身学习效率，都需要现实中的实验来回答。

但这条思路至少为我们提供了一种不同的想象。

我们不再只把智能看作某个经过训练、等待接受任务的静态模型，而是将它理解为一个不断经历世界、积累知识、改变自身的动态过程。

它的发展也不必拥有唯一的终点。

**我们不是为了让智能永远追逐某个最优的未来，而是希望它拥有越来越强的能力，去理解、探索和创造无数种可能的未来。**
