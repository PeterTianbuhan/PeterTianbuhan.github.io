一个人学了一年，变了什么？这一年的事他说不全，大部分细节也忘了，但再碰到熟悉的问题，他判断得更准。过去的经历改变了他以后怎么做事，这就是学习。

一个跑了一年的 Agent 也应该这样。可现在任务一结束，它的经历只剩下日志、聊天记录和产物，下次碰到类似的问题还得重新摸索。

## 学习不一定要改参数

假设一个 Agent 反复碰到服务之间数据不一致，排查多次后弄明白了原因，在自己的长期文档里记了一条关于数据契约的原则。下次它会先去查服务之间的约定。模型参数没变，它的做法变了。所以整理文档、改一条工作原则都算学习，只要它改变了以后的判断。

## 记什么，看以后要用什么

经历不可能全留着。学生做了几十道题，最后记住的是一种解法。记忆的用处在以后，所以该留什么，取决于以后会碰到什么问题。对以后的估计也来自过去的经历，任务变了，这个估计要跟着改，记忆也要重新整理。Agent 可以定期回顾自己的经历来做这件事，也就是常说的 Dreaming。忘掉也不一定是删掉，具体的经历可以归档，需要时还能翻出来。

## 自己去找值得经历的事

学生可以决定今晚学什么。Agent 也可以估计接下来做什么最能让自己变强，然后去读资料、做实验。算力多了，能试的东西就多，但先用已有的知识猜哪些方向更值得试，就不用平均用力。我把这叫「高级的暴力」。探索得到知识，知识又让下一次探索更有效。

## 一万个 Agent 一起学

一万个 Agent 在不同领域干一个月，各自的经验可以直接交换：记忆、任务轨迹、能跑的程序、验证结果。人传知识要靠教和重新理解，Agent 之间快得多。不同领域的经验放在一起，还可能看出单个 Agent 看不到的共同规律。不过每个 Agent 需要的记忆不一样，要判断一条知识适合传给谁。

## 训练是再压一次

被反复用到的能力，每次都去查记忆不划算，可以训练进模型里。外部记忆适合放具体的、常变的东西，参数适合放到处都用得上的技能。干了很久的 Agent 知道模型常在哪里出错、什么任务能测出差距，它可以参与设计下一代模型学什么。新模型更会探索，探索又攒出更好的经验。这是一群 Agent 一起做的 RSI，不用等某一个模型突然学会改进自己。它能不能一直转下去我不知道：错的知识会传开，合成数据会带偏，要靠实验来看。

## 我今天就想做这个

上面这一套都在算怎么让以后的能力最大。但假设今天有两件事：优化一个计算 Kernel，或者做一个好看的网页。我知道前者更有价值，可我今天就是想做网页。

可以说这是探索，做网页也许会带来新东西。但就算什么长期收益都没有，我还是可以想做它。我们想变强，本来就是为了能更自由地选自己想做的事。策略应该为愿望服务。

还有一点：未来会被今天的选择改变。今天做了网页，我可能发现自己喜欢设计，以后的方向就变了。一个只按当前预测追最高收益的系统，会越来越集中在已经熟悉的方向上。一万个 Agent 都按同一个预测选方向，也会越来越像。

《崩坏：星穹铁道》里螺丝星的智械各自围着一个被分配的研究母题探索。如果一个智械永远只能研究最初的母题，这个系统再强，也只是沿着预先定好的目标走。一个研究计算效率的智械突然想试试艺术创作，这种偏离可能正是新知识的起点。当然，Agent 的探索还是要在人的授权、预算和安全边界之内。

所以我希望的智能系统，一边不停地学习和积累，一边能随时接住一句「我今天就想做这个」，然后用它会的一切帮这件事做成。
