## 起因

我很爱听爷爷讲故事，也总觉得他肯定还有更多故事没讲过。前段时间我想帮他把一生记下来，他很激动，接着又说：「我文化不行，写不出东西。」

我那时候意识到，现在记录一个人的一生，成本已经可以低到只剩下说话。

后来我妈听说了，也说想用。所以它不只是给老人用的，每个人都有一些不该跟着记忆一起消失的事。

## 能做什么

打开 App，说话就行。agent 在后面慢慢把讲的东西整理成人生时间线、见过的人和去过的地方。

- 原话和录音都留着，整理出来的内容不会盖掉原话。
- 时间可以说「小时候」「那年夏天」，不用编一个精确的日期。
- 听不清的名字、前后对不上的地方，它先记着，以后再说，不会一直追问。
- 所有东西都存在自己的设备里，可以看、改，也可以导出带走。

## 为什么单独做一个 App

爷爷奶奶大概不会去打开 ChatGPT，更不会专门研究一个网页该怎么用。我想让 agent 用足够简单的方式走到这些人手里，所以把它做成了一个单独的 App：装好，填一个 API key，之后只要说话。

已经在用 agent 的人不用装 App，仓库里有一段 prompt，发给自己的 agent 就能开始讲。

## 怎么做的

界面用 React 写，用 Capacitor 打包成手机应用，agent 部分用的是 pi。模型用自己的 API key，直接连模型服务商。MIT 协议开源，有 Android 安装包。

## 最后

我自己也在和 agent 一起整理自己的记忆，回顾自己的生活，这件事我挺享受的。这个项目不大，但我很喜欢，它可能是我做的第一个真的有价值的开源项目。
