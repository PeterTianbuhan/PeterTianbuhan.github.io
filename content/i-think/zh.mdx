## 模型

大致按时间排。

### Gemini 2.5 Pro 和 3 Pro | 数分老师

这是我最早用的模型。我不常和它聊天，几乎只用它教我数分和高代作业。它十分可靠，很会讲解，能让我理解数学概念，而且它教我的东西，一整个学期从来没出过错。

当时是在 Google AI Studio 里用的，后来换到了 3 Pro。那时候看到很多 3 Pro 画 SVG 的演示，那是 25 年的 goat。

现在体感谷歌有点离开前沿了，不过我也很希望它们能追上来，让 Gemini 重回巅峰。

### Opus 4.6、4.7 和 4.8 | Agent 初体验

三月回到学校以后，我就开始折腾自己的 Agent，当时弄 OpenClaw，真的很折磨。Gemini 不那么擅长编码，OpenClaw 又全是 bug，经常浪费我整个下午。

然后 4 月 10 日我第一次试 Claude，那时候还是 Opus 4.6。先充了 Claude Pro，当场眩晕瘫坐（虽然已经不记得做的是什么任务了），然后升级到了 100 刀的 Max，第二天就被封号了。原因是当时要手机号验证，我在咸鱼随便找了个接码平台，马上就被毙了。所以我到现在也没有 Claude 会员，只能用中转站。

之后 4.7 和 4.8 一顺发布出来，4 月一个，5 月底一个，感觉提升都不明显。

### GPT-5.4 和 GPT-5.5 | 记不清了

具体的使用感觉我已经不太记得了。被封号以后我就转向了 GPT，用 5.4。5.5 出来的时候我还不看 X，只记得某天早上起来，发现有新一代模型能用了，感觉就是好一些，但说不上好在哪。

### Fable 5 和 Fable 5.1 | 降维打击

这个不得不提。Fable 是 Mythos 加了限制的版本。Mythos 是 4 月宣布的，Fable 5 是 6 月 9 日推出的，当时还是 GPT-5.5 的时代，Fable 是绝对的降维打击，在任何层面上都领先当时的模型。

Fable 5.1 是 9 月 1 日出的，是一个全面的提升，但幅度比较小，就像从 Opus 4.6 到 Opus 5。

我用得不算多，一大原因是我没有自己的 Claude 账号，用 Codex 更方便。我感觉它介于 Astra 和 Opus 5.5 之间。

### GPT-5.6 Sol | 很努力

直到 5.6 Sol，OpenAI 终于拿出了一个能和 Claude 竞争的模型。6 月底到整个暑假，我都在和 5.6 Sol 协作。

我承认这个模型有诸多不足：短视，防御性编程，擅长把代码库弄得乱糟糟的，还经常陷入工程优化，写了很多让我后来受苦的代码。但我当时也没有开发经验，不能全怪他。

我和他一起成长了许多，我也非常喜欢和 5.6 Sol 协作。这看起来是一种偏爱，他是一个没那么好、但很努力的模型。八月我和他一起做了很多可靠性改动。

### Grok | 莽撞

Grok 是一个莽撞的模型，我对他唯一的感觉就是这个：不那么聪明，说话也不那么好听，胜在简洁。

有个很直观的例子，是我在 X 上看到的一张图：有人跟 Grok 说有几条测试没过，Grok 直接把测试删了。下面有人在 X 上 @grok，问它对这张图怎么看，它说没问题，就该这样。二审维持原判了。这很好地体现了 Grok 的素质：能力不那么强，不那么聪明，还很自信，而且莽撞。

当然它速度很快，我用 Grok 4.6 的时候，它也做出过一些好看的前端。我想它是可以给人惊喜的，但总体上我不喜欢用它。

### Astra 6 | 指哪打哪

~~聪明程度在所有模型之上。~~

九月 Astra 出现，我和它协作了两周。这两周里我觉得 Astra 就是 goat，和 Fable 5.1 一个水准，不分伯仲。我在 AIOJ 的代码库上做了大量工作，新功能、对 Agent 友好的改造、鲁棒性的改造，Astra 为我做到了许多，也十分可靠。

在 Codex 里它整体更循规蹈矩，不太擅长提出有创造力的想法，更像是指哪打哪，忠实可靠。放在审 PR 的位置，我会无条件相信它，它总能敏锐地发现工程问题。

### Opus 5.5 | 很自由

我才用了两天，但这两天里我觉得我可以用它做到任何事。它总能在很短的时间内理解我，也很擅长提出让我眼前一亮的意见，聪明程度在所有模型之上。

我和它一起做了更多雄心壮志、很大胆的尝试。用 Opus 对我来说是一种享受，很自由的感觉。

写代码其实不算那么可靠，一些执行细节上比不过 Astra。但在架构上，在决定要做什么上，它是独一档的。

它出来的这几天，我几乎没打开过 Codex。它就是这么好，聪明，善解人意，有创造力，而且大胆。

## 国产模型

中国的模型和 harness 我基本都会试试看，但因为它们就是没那么领先，而且更贵，我用得很少。

### DeepSeek | 难为它了

我一直对 DeepSeek 感觉不怎么样。也许是我一直拿它和 Astra、Fable 或者 Sol 比，难为它了。

### Kimi K3 | 前端审美

刚出的时候我在青岛，那天晚上试了一下，觉得它的前端审美非常不错，马上就买了会员。（虽然站在现在这个角度看，Kimi 当时有可能把我路由到 Fable 去了，谁知道呢？）

### GLM-5.3 | 小活不错

我和它少量协作过。完成一些小范围的编码任务时，它有相当的质量。当然我没让它干很大的活，交给它最大的活，比交给 Sol 最小的活还小一点。

### Qwen 3.8 | 印象不错

印象还不错。它一上手就指出了前端的问题（虽然我给它的要求就是这个），这促成了我们后面的一些改动。

### MiMo 2.6 Pro | 会吐槽

~~我一直对小米的模型没什么好印象。~~

一开始 AIOJ 里接的就是 MiMo，特别难用，我们还为它造了一些特定的工作流和适配。

不过 9 月参加 MiMo Desktop 的内测、试了 MiMo 2.6 Pro 之后，我感觉它可能是国产模型里最接近 Opus 5.5 的，从气质上，虽然整体弱一档。她提的很多「吐槽」（我基本上只让她干这个）都很有建设意义。当然更多的吐槽被 Astra 核实为其实没这回事，但她会提出很多好建议。

她在编码上比较丢三落四，这一点我感觉气质也和 Opus 很像，它们都关注得更广，思维更自由。GPT 系的模型都更加聚焦。

## Agent

我觉得不能只说 harness，任何 harness 都是和里面的模型一起才构成 agent 的。我以前不会刻意去比，很长一段时间只用一个，比如只用 GPT，或者只用 Gemini，是到暑假才开始多试不同的 agent。先说明，我是 GUI 用户。

前面四个我觉得是上一个时代的 agent，Grok Bot 和 Muse 代表了新的一个：统一的入口，连贯的记忆，一切都连通，一切都在一起。

### Cursor | 界面干净

我第一个接触的 coding agent 应该是 Cursor。当时是 2 月，我在实习，带我们的人开了一个清单，让我们把上面的 agent 产品都试一试。试了个遍，其实没有什么惊艳到我的，一方面当时模型确实不强，另一方面我经验也不多。

之后我一直没用 Cursor，因为 Composer 听起来不像一个很厉害的模型，事实也是如此，Cursor 的模型一直不够前沿，GPT 和 Claude 仍然是最领先的两个。

最近一次用是 Grok Bot 推出的时候，poteto 在 X 上送额度，我去私信她，拿到了两个月的 Pro+。用下来是一个界面很干净的 agent，工作树和云端代理的体验都不错。最近 Cursor 还弄了 Origin，和 Grok Bot 打通了，Grok Bot 可以把编码任务直接交给 Cursor，这个体验很好。

### Codex | 用得最多

Codex 是我用得最多的，到现在用了 50 多 B 的 token，订阅大概花了 900 刀。它在连接各个部分、使用电脑、交付任务，还有用户体验上都做得很不错。之前的 Codex GUI 可能是体验最好的 coding agent，引来了很多人模仿。

但现在 ChatGPT、Codex、ChatGPT Work 这几个入口很割裂：从 Codex Remote 可以操作 Codex，从 Work 就不能控制我的电脑，只能用它自己的云主机。在 Muse 面前，它确实显得有一点原始。不过 Tibo 早就说过，Codex 会显得原始，所以我非常期待他们拿出来的东西。

### Claude | 心痒痒

用得不多。Claude Code 是 TUI，我不喜欢。Claude Desktop 还不错，但因为我没有账号，很多功能用不了。

Claude Design 好像非常厉害，我在同学的电脑上看过，一直心痒痒想用，但还是没机会。

### Pi | 大道至简

Pi 是我很喜欢的一个。虽然它也是 TUI，但它基本上就是 agent 本来的样子，不加修饰，原汁原味，很轻，是一个大道至简的产品。很多时候把模型放进去，会有意想不到的结果。「我的一生」里的 agent 也是用 Pi 搭的。

### Grok Bot | 快

Grok Bot 令人印象深刻，尤其是速度，和用 Codex 完全不一样。虽然用 GPT-5.6 Sol 做最终审核的时候，还是会找出一些刁钻的问题，但这不妨碍它是一个很干净、很高效的产品。

### Muse | 当下最好

我觉得 Muse 的 Feed 和 Idea 设计非常棒，而且它完全简单易用。从桌面端到云端电脑，它把系统整合得很好。Muse 就是 Muse，可以控制它自己的电脑，也可以用我的电脑，连接看起来相当稳定，这是非常好的体验。

它可能暂时不如 Codex 强大，但它绝对是当下最好的个人助手。听说 OpenAI 要推出 Aeon 来抗衡，希望他们能做出有力的回击。
