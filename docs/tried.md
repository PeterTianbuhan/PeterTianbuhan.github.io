# 试过但没用上的方向

代码都搬到了 `../homepage-lab/`，git 历史里也还在（`6078894` 之前的提交都有）。这里只记没用上的原因。

## 终端首页（2026-09-17）

像素字体、窗口外框、zsh 式命令导航，未名湖用字符画，配色跟着时段变。Peter 说当时做终端是因为还做不出好看的东西，后来想要一个“真正能代表我”的首页，就换掉了。
→ `homepage-lab/terminal-homepage/`

## 风景首屏（2026-09-22 ~ 23）

先用同学拍的一张山雨照片做 WebGL 视差，原图太小（1280×853），又被压缩过。后来改用代码画西山：7 层山脊，太阳位置按北京实时算，接了实时天气。Peter 觉得“美感不是很足”。
→ `homepage-lab/scenery/`

## 来处（2026-09-23）

按人生章节（嘉鱼 → 武汉 → 北京）一章一张二游风格的主视觉。先用代码画 SVG，被说“不是很丰富和精致”；后来改用 AI 生图，细节对了，但看着像“上世纪漫画”（部分原因是 anime 超分把细节抹成了色块）。这时 Peter 最喜欢的是一张一笔一笔画出来的钢笔水彩北大，那张后来成了首页。来处本身没想清楚，暂时不做。
→ `homepage-lab/laichu/`

## 故事短片（2026-09-25）

想把生活里的片段画成短片，第一个是寒假在华师一操场表白。第一人称 3D 操场的透视和人群都对，但画面寡淡，人像火柴人；改画单帧插画后有了光和景深，但画出来不像她。结论：代码画不好具体的人。以后要做，人物得由人来画。
→ `homepage-lab/stories/`（私人内容，不上网站）
