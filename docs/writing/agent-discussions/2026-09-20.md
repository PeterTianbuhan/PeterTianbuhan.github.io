# 关于 Agent 的理解：第一轮讨论记录

日期：2026-09-20；参与：Peter、Codex。

用途：保留这一轮思考，供下一次讨论接续。属于写作资料，尚未整理为公开正文，也未确定未来文章的数量与结构。

这套讨论可以容纳 Peter 如何使用 Agent、如何理解模型与 Agent 的关系、构建智能体的思考，以及对未来智能的想象。今天从人对智能的追求谈起，逐渐走到了经验如何被机器承载、系统如何从运行中学习，以及这种学习为什么仍然显得迟缓。

下面先记录 Peter 的观点，再单独整理讨论中的补充与分歧。除明确标出的原话外，均为对发言的整理；Codex 的补充不视为 Peter 已经接受的结论。

## 一、Peter 的思考如何展开

### 从智能、泛化与时间积累开始

Peter 的起点是：人一直在追求智能，但对于智能是什么、意识是什么、人为什么会有意识，仍有许多未解的问题。他尝试从行为上寻找一个可用的理解。

程序中的条件判断与分支，也能应对复杂环境；他的初始表述是，一旦遇到没有提前编码的条件，这种应对就可能失败。因此，一个检验智能的指标，可以是泛化能力：把它放进陌生环境，它能不能接收反馈、选择动作，再根据结果优化动作？关于这里“程序”的含义，Peter 随后作了澄清，见第五节。

这里自然牵涉知识和记忆。时间向前，大脑发生改变，过去的经历能够在当下发挥作用。Peter 将这理解为从时间积累中获得力量的机制。他暂时提出，智能需要感知、灵活决策和积累智识；在这个意义上，智识与智能很难分开。

### 人类知识的结构，以及机器学习为何可能成立

Peter 把当下的机器学习称为一种“很高级的暴力手段”：人从对自然、神经系统的有限理解中获得灵感，创造零部件，通过大规模计算与训练获得能力。他更倾向于把 LLM 看作这些积累的一个暂时集大成者。

让他感到神奇的是，相对于能力覆盖的广度，模型用一个并非不可想象的参数规模，就表现出了非凡的智能。他由此联想到《如果知识能够自己生长》中的思路：人类知识可能存在大量可复用的共同结构，知识的内核或许比表面呈现的体积小得多。

语言是一个极好的起点：广泛、相对有限、容易利用，并且高效。但他相信这只是开始，人们会逐渐找到其他领域采集数据、表达状态的方法。

他提出了一个较强的猜想：如果某件事背后确实存在相对稳定的 core，那么这种大规模学习路线就应该能够奏效；当模型的容量足够容纳这个 core 时，现象的外在部分可能在训练中逐渐被剥去。

这个猜想尚未得到完整论证，尤其“存在稳定结构”如何推到“训练能够找到它”，是本轮讨论留下的重要问题。

### 经验开始拥有新的载体

Peter 对世界模型和具身智能最终能够成功抱有很强的信心，同时对当下成果距离成功还有多远持严格看法，最初甚至用了“还没上路”来形容。他在这里表达的是对方向的信心与对当前完成程度的不满意。

他对当下变化的一个核心理解是：我们找到了一种把经验高效传授给机器的方法，而机器可以大规模运行，带着这些经验继续向前。

这里的“经验”很宽泛，包括知识、哲学、思考和推理。Peter 最初强调经验从人际流转进入机器载体，随后补充：工具、机械和传统程序早已承载人的经验，这一轮变化需要放在更长的历史中理解，见第五节。传授的成本未必总是低，但人不再是经验的唯一载体。

由此，他提出了几个类比：进化是否可以类比预训练，人的生活是否可以类比后训练，上下文是否可以类比短期记忆？模型训练中的奖惩，与自然选择对遗传特征的筛选，是否存在值得研究的共通之处？这些首先是帮助理解的类比，还没有被认定为机制上的等同。

他还提出：“人类智能，抛开经验，还剩下多少不可替代性呢？”

### 对通用、知识工作与未来的强判断

Peter 怀疑哲学意义上的全知式通用是否可达，也不认为一个智能体会理所当然地突然通晓万物。但他保留了另一种想象：当世界模型接触足够多的信息后，会不会抓住一些极为底层、能够解释广泛现象的法则？

他对知识性工作的判断更强：知识性工作可能已经被解决，人能做到的，LLM 在合适的适配下都能做到；暂时做不到的事情，在获得数据之后也能够做到。这是他在本轮中明确提出的立场，尚未在讨论中转化为有明确边界的可检验命题。

他也充分相信智能可以超过人类。人脑的复杂度至少是有限的，这使他不把人类看成智能发展的必然上限。经验能够被新的载体继承和扩展，让他对未来充满希望。

### 什么算真正学会了

当 Codex 问，一个 Agent 经历失败后成功，究竟应该留下日志、步骤、解释还是参数变化时，Peter 把问题落到了行为效果上：

> 下一次做，做对的概率提高了，同时整体上，做其他事情退化率不至于不可接受。

这个回答给出了本轮最清楚的学习标准：经验应当让未来表现改善，同时不能以不可接受的其他能力损失为代价。保存了多少内容，并不直接等于学会了多少。

Peter 认为，模型的智能很大程度上在参数中。Skill、提示词等主要在利用模型的 in-context learning；他称其为模型能力中的“一小部分”，但也认为这部分能力十分迷人，与人类学习有连通性，几乎就是模型面对全新事物时的学习方式。

在他的理想中，运行结束后，模型能够复盘“应该怎么做”，形成好的数据，更新参数，让下一次表现更好。他认为，这在功能上接近人学会某项技能的过程。

### 一种朴素的 RSI

Peter 设想的路线是：运行一段时间，积累各个领域的经验数据，再进行一次较大的训练，让这些经验被模型吸收；更强的模型随后投入新一轮使用。

他认为这已经可以叫作 RSI。现阶段循环中需要人，并不使这个循环失去意义。模型能够自己训练自己、改进训练方法，可以被理解为复盘能力与学习能力进一步提升；未来人所承担的部分可能减少。

这里的递归关系在于，前一轮获得的能力，可以参与下一轮经验的获得和整理。更强的模型有机会探索更难的问题、识别更细微的错误，再产生更好的学习材料。

### 数据、复盘与推演

Peter 随后把重心放到数据上。他认为，在当下模型的结构里，数据“几乎就是一切”；能够自主从真实任务中获得反馈数据，是提升能力的关键。

数据也不必只来自日常真实任务。他举出 OpenAI 利用现有模型驱动的智能体，参与后续模型安全训练的例子：系统可以主动产生有训练价值的情境。

另一个来源是推演。人会回想自己哪里做得不好，在脑中尝试其他路径。Peter 认为，这些过程可以被机器复刻。如果判断“哪里错了、应该如何改”的能力提升，就可能缓解某些领域的数据匮乏。

他提出一种可能性：未必需要反复进行上万次真实探索；数百次探索，加上数万次复盘推演，也许就足以产生好的效果。这里的数量表达的是设想中的放大关系，并非本轮已经验证的实验比例。

他将 Dream-RSI 受到关注与这种可能性联系起来：昂贵的经历可以被反复利用，产生新的学习收益。

### 批量学习的合理性与迟钝

讨论最后，Peter 认为，这条运行、积累、复盘、训练的路线，是当下看起来最合理、最 promising 的路径。

他并不执着于实时更新参数。虽然那看起来最接近人，也很美好，但他直觉上认为工程难度更高。与此同时，大规模参数更新的周期较长，系统在整体上又显得“略显愚笨”。

这一轮停在这里：我们看见了一条可能让智能持续成长的路，也看见了经验已经发生、稳定能力却迟迟没有改变的间隔。

## 二、讨论中的补充、质疑与尚未解决的分歧

以下主要由 Codex 提出，记录它们是为了后续检验，不代表 Peter 已逐项认可。

**智能与程序的边界。** 程序也可以实现通用算法与学习机制，因此“程序无法应对未编码的具体情况”需要收窄。可以进一步研究的是系统能否根据经验改变处理方式，以及这种改变能迁移多远。智能的行为能力与主观意识，也可以分别讨论。

**稳定 core 与可学习性。** 存在可表示的规律，尚不保证现有数据足以识别它，也不保证训练会找到它。找到规则后，运用它仍可能需要昂贵计算。模型容量、数据可辨别性、训练方法和推理成本，需要分别考察。

**知识压缩与能力证据。** 有限模型展示广泛能力，支持知识具有共享结构的猜想，但尚不足以证明全部人类知识的复杂度很小。知道底层法则，也不等于知道所有具体状态或能快速计算所有结果。

**“知识性工作已经解决”的边界。** Codex 对这个完成时判断保留分歧。需要进一步明确“合适的适配”允许加入多少人工工作、新数据、工具、训练和计算，以及要求多高可靠性。可能实现与已经实现，仍需区分。人脑有限也不足以单独确定实现机器超越的方法与成本。

**参数与 Agent 整体的学习。** Codex 认为，“上下文学习只是一小部分”尚无明确衡量依据；有效的外部记忆、工具或策略更新，也可能改善整个 Agent。Peter 更关注经验最终进入参数、成为稳定能力的路径。两种观察尺度如何配合，值得继续讨论。

**复盘的可靠性。** 一段成功轨迹可能包含偶然因素，复盘也可能把事后才知道的信息塞回早期决策。数万次推演可能共享同一个错误假设。需要区分已有信息尚未被充分利用，与关键事实根本没有被观察到；后者通常还需要新的观察或实验。

**RSI 的含义。** 本轮讨论采用的是能力改善反过来帮助下一轮改善的宽泛理解。循环是否存在、人参与多少、改进能否加速，是不同的问题。已经形成反馈不保证收益无限持续，也不自动意味着智能爆炸。

**学习延迟。** 最后一轮 Codex 提议，把经验何时影响行为、何时进入参数分开考虑：上下文即时调整，跨运行记忆承接近期成果，参数更新吸收较稳定的能力。外部经验积累也会带来检索和协调成本。这只是一个待讨论的方案，Peter 尚未进一步回应。

## 三、本轮查阅的研究线索

这些资料用于支持或约束具体推论，不替代 Peter 的判断；以下记录的是本轮查阅到的内容。

- [On the Measure of Intelligence](https://arxiv.org/abs/1911.01547)：提出从获得新技能的效率理解智能，并考虑经验、先验与泛化难度。可用于继续讨论“学得快”与“已经会得多”的关系。
- [Understanding deep learning requires rethinking generalization](https://arxiv.org/abs/1611.03530)：神经网络也能拟合随机标签，提醒我们容量足够并不自动意味着提取到了规律。
- [Mastering diverse control tasks through world models](https://www.nature.com/articles/s41586-025-08744-2)：Dreamer 利用学习到的环境模型改进行为，说明世界模型用于决策已有具体成果；同一算法在多个任务上分别学习，仍不等于一个系统已经获得开放世界的持续通用能力。
- [STaR: Bootstrapping Reasoning With Reasoning](https://arxiv.org/abs/2203.14465)：模型产生推理材料，借助已知答案筛选或重新生成，然后训练并重复。是自生成材料参与学习的具体例子。
- [Thinking Fast and Slow with Deep Learning and Tree Search](https://arxiv.org/abs/1705.08439)：Expert Iteration 用搜索结果训练网络，再用网络指导后续搜索，体现两种能力相互促进的循环。
- [GPT-Red: Unlocking Self-Improvement for Robustness](https://openai.com/index/unlocking-self-improvement-gpt-red/)：OpenAI 介绍利用自动红队发现攻击，并用于后续模型的对抗训练。系统会实际测试目标模型的响应，其反馈有可观察的依据。
- [Dream-RSI 项目介绍](https://www.dream-rsi.com/)：把真实探索的历史树作为重放环境，在已记录的分支与结果上比较探索策略，保持底层模型不变，改进策略代码。它支持经验复用可以减少昂贵探索的判断；不能据此推定任意未见环境的结果，也不是本轮参数训练设想的直接实现。重放成本低不等于整个系统没有计算成本。

写成正式文章前，需要按实际采用的论据进一步核对原论文、实验范围与比较条件。

## 四、下一次可以从哪里接着谈

最自然的接续点，是最后留下的那种迟钝：一个系统已经获得经验，却要等到下一轮训练才稳定受益。值得继续问，它在等待期间应当怎样利用经验，什么经验值得进入参数，以及怎样避免迅速吸收一个错误判断。

另一个可以深入的地方，是“好数据”究竟好在哪里。它可能是一条成功轨迹，也可能是失败之间的对照、一个暴露前提错误的反例，或一次能够区分几种解释的实验。数据的价值应当最终回到 Peter 提出的标准：后续做对的概率是否提高，其他能力的退化是否可接受。

更远一些的问题仍然敞开：当模型越来越会获得、检验和吸收经验，哪些限制来自模型，哪些来自环境与反馈？Agent 与模型的分工会怎样改变？Peter 在实际使用与构建中遇到的具体经历，可以成为检验这些想法的材料。

这些线索以后可以各自发展，也可以重新交叉组合。目前保留的是一段持续讨论的起点，不设定固定篇数或文章目录。

## 五、同日续谈：从工具、程序到新的认知来源

本节记录首版记录稿完成后 Peter 的补充。它修正了前面“程序与智能”“经验开始进入机器”两处容易产生误解的表述。

### 智能也可以是程序

Peter 澄清，他认为智能本质上也仍然是程序、算法。他此前说的“高级的暴力”，正是在说这种计算实现：参数可以被理解为状态压缩的记录，Transformer 等算法让这套机制运转。

因此，他先前用来作对比的“程序”，更具体地指人把自己对于某个问题的解法写成通用解决方案这件事。他不再把程序与智能分成两个截然不同的类别，关注点转向：人先理解问题并写下解决方法，与系统从经验中形成解决能力，分别承担了怎样的工作。

### 经验早已从人流向工具

Peter 补充，经验流向计算机并非这轮 AI 才开始。更早的机械装置和工具，也凝结着人的智慧，使下一次做事更省力；人把某件事研究得足够透彻，就可能将它自动化。

他最近常想到一个类比：写代码与魔法世界念咒语，可能没有本质区别。计算资源有限，魔力也有限；掌握正确的咒语，就能驱动计算机完成大量事情。他将图灵机所代表的计算突破，放在这条更长的历史脉络里理解。

从结绳记事开始，人寻找记录状态的载体；制造工具，则帮助人更高效地改造状态。程序延续了这种把认识固化为可重复执行能力的过程。

### 这一轮变化发生在哪里

Peter 暂时提出两个区别：其一，我们拥有了一种覆盖范围极广的算法，把过去的知识很大程度上集合起来；其二，这套系统具备探索能力，开始获得超出人类已有认知的结果。

他用“数学家们已经跟不上 AI 的进展”表达对当前变化的判断。他尤其关心的是，社会的智力结构出现了新的来源：从纷乱的数据中提取共性、形成判断、作出响应，这些认知工作开始由 AI 承担。

Peter 不认为存在一条可以先验划定的界线，规定某种发现必然只有人能做到、AI 永远不能做到。他仍然相信，未来会到来一个在一切层面超越个体能力的时代。这是他表达的未来判断，并非本轮已经完成的证明。

### 从人际传授推向机器可学习性

Peter 提出一个相对弱一些的论证：人要把自己的领会传授给别人，需要将其压缩，通过语言或其他交流形式传出去。既然一部分认知能够被表达在语言中，LLM 就应当有学会它的可能。

沿着这个想法，人类社会发展以来通过语言流转的认知，都可以成为模型理论上的学习对象。模型可能从中学到一些高维特征，学会在某种环境下形成某种看法，并在新的情境中运用它们。

在这条脉络里，LLM 尝试通过大规模学习从人的语言中获得人的智识。Peter 认为，这在很大程度上已经成功。人的精力与能力有限，而这些能力的载体可以继续扩展，因此他对未来充满希望。

### Codex 的回应与检验线索

这次补充使讨论的重点更清楚地落在认知分工上：人类一直在外化经验，今天进一步把寻找规律、形成解决方法的工作交给系统。这个变化有连续的历史，并不意味着自动发现规律始于 LLM；Peter 所强调的广度、统一性和探索能力，可以分别检验。

“参数是状态压缩的记录”可以作为直觉，但需进一步明确压缩了什么。参数并非经历的逐条存档；训练会保留、忽略和重组信息。Transformer 架构、训练方法、数据与运行时计算也需要区分，不能用单一名称代替整套机制。

语言传授的论证，为机器学习人类认知提供了一个有力的可能性思路。但表达出来，不保证文本单独包含全部理解条件；人与人还可能共享感知经验、背景知识与实际练习。需要区分某项能力原则上可被机器学会，与特定 LLM 仅靠现有文本训练就足以学会它。这一限定不等于承认人有不可复制的特殊能力。

数学方面，Codex 起初引用了 [AlphaEvolve 的官方介绍](https://deepmind.google/blog/alphaevolve-a-gemini-powered-coding-agent-for-designing-advanced-algorithms/)，其中报告了模型与自动评估组成的系统改进已有数学结果，例如找到 11 维接吻数问题的 593 球构型。这支持系统能够产出人类此前未知成果的判断。不过，仅用这个较早案例回应 Peter，未充分反映最新进展；后续按 Peter 提醒进行的核查与判断修正，见第六节。

由此留下一个新的接续方向：当机器能够承接已有认识，也能够参与产生新认识时，人类社会知识的来源、继承方式和分工会怎样变化？它可以与此前的学习、数据和 RSI 讨论相接，也可以独立展开。

## 六、最新研究核查：AI 是否已经走到人的前面

核查日期：2026-09-20。Peter 要求检查数学界的最新突破、千禧年问题与 AI 顶会近期投稿，认为这些已经充分支持“AI 走在人的前面”。本节记录查阅结果及 Codex 对上一轮回应的修正，不代表逐行验证了数学证明或复现了研究实验。

**Navier–Stokes。** OpenAI 于 9 月 8 日公布解析证明与 Lean 形式化，报告了光滑外力下三维 Navier–Stokes 方程的有限时间爆破，对应千禧年问题正式表述中的 C、D 两种情形。官方说明报告约一万个并发 Agent 参与相关求解，88 小时得到结果，随后另用 17 小时完成形式化与验证。这里包含研究人员选择方向、调配资源和组织中间结果的工作。[OpenAI 公告](https://openai.com/index/navier-stokes-solution/)、[证明论文](https://cdn.openai.com/pdf/32d9f210-8b73-45e0-91bc-82a30aef8a9a/navier-stokes.pdf)

Clay 数学研究所于 9 月 11 日回应，使用“apparently been settled”描述这一问题的状态，并说明正式评估与贡献归属程序会审慎进行。不能把这写成 Clay 已经完成最终认定；同时，这已经是比此前只举局部构型优化更强的前沿研究证据。[Clay 官方声明](https://www.claymath.org/news/navier-stokes-announcement/)

**ScientistTwo。** 9 月 17 日公布的预印本及项目页报告，在取自近期顶会成果的 107 个研究任务中，系统在 86 个任务上改进了人类基线指标。它生成假设、开展实验、修改方法并生成论文。论文质量比较采用自动评审模型，因此不能把这些结果写成 86 篇论文已通过顶会的人类同行评审。这是研究团队报告的实验结果，本轮未独立复现。[论文](https://arxiv.org/abs/2609.19644)、[项目与结果](https://scientist-two.github.io/)

**近期投稿潮。** ICLR 2027 官方时间表显示，摘要截止日为 9 月 18 日，全文截止日为 9 月 25 日。截至本次核查，尚未找到官方确认的最终完整投稿总量，因此未将网络流传的五万或六万数字当作已确认的完整研究成果数量。官方 9 月 2 日投稿政策说明承认 AI 降低了生成论文的门槛，并指出评审资源承受压力；这支持研究生产与筛选方式正在改变，不能单凭数量推断原创研究质量全面超过人类。[作者指南](https://iclr.cc/Conferences/2027/AuthorGuidelines)、[投稿政策说明](https://blog.iclr.cc/2026/09/02/submission-policies-for-iclr-2027/)

**能力并不均匀。** 一项 7 月发布、8 月更新的研究，让当时的 Agent 尝试两篇未发表 NeurIPS 2026 投稿的研究问题：系统完成了工程工作，但原作者判断它们未在核心问题上取得实质进展。这个小样本、特定系统的结果不能代表 9 月新系统的上限，但提示我们应分别考察提出问题、研究判断、实验执行和得到成果的能力。[研究论文](https://arxiv.org/abs/2607.27191)

Codex 据此修正回应：AI 系统参与产生前沿新知识已经有实质且不断增强的证据，不能只把 Peter 的判断放在遥远的可能性层面。更明确的讨论命题可以是，AI 已在一些研究任务中越过人类此前达到的结果，并在研究生产过程中承担越来越多认知劳动。它是否在所有研究环节稳定领先所有专家，属于更强的命题，现有这些证据尚不能一并证明。Peter 所说“社会的智力结构出现新的来源”，获得了比上一轮回应承认的更强支持。

## 七、同日续谈：AI、程序与计算资源的分工

### Peter 的观点

Peter 提出，暴力算法好用，并不意味着所有地方都应该使用它。AI 产品提高效率的宣传有真实依据，但如果一件事人顺手就能做完，让 AI 接手未必有足够的必要性，界面操作就是他的一个例子。

他预期人们会在 AI 与传统程序之间找到平衡。程序不会消亡；对于已经明确、能够重复执行的工作，它仍然是一种资源占用更少的做法。在他的理想体系里，AI 处理此前难以解决的复杂情境，重复性工作继续交给程序。

他观察到的一种社会导向，是让 AI 承担底层工作，而他主张 AI 更应该承担顶层工作。这是 Peter 的观察与价值判断，本轮未将其当作经统计验证的全社会共识。

Coding Agent 的价值因此很突出：它能够迅速把重复性工作交给代码，使解决方法成为可以反复执行的东西。这延续了人类在互联网时代把工作自动化的方式，也与前面关于工具承载智慧的讨论相接。

Peter 对以逐页填写表单、操作电脑为主要路径的方向持明确的否定态度。他更认可应用提供面向 Agent 的 CLI 等接口，让系统直接操作应用能力。他认为，为有限的页面决策消耗大量 token 并不值得。

### Codex 的回应与待检验条件

这提出了参数更新之外的一种经验积累：Agent 可以把经过验证的做法变成可执行程序，使下一次同类工作减少推理与试错。编写、测试和判断适用条件仍然有成本，但稳定任务可以在后续重复执行中摊薄这些成本。

“顶层”可以进一步具体化为理解目标、处理歧义、选择方法、发现异常与修改规则；确定的查询、计算、数据搬运和批量执行，则交给代码。分工依据可以是某一步是否还需要判断，而不必按工作名称或组织层级划分。

CLI 是一种可能的载体，API、结构化工具等也可以承担这个作用。关键是接口能否直接表达任务所需的操作、给出明确状态与结果，并方便组合。换成 CLI 后若仍让模型逐条阅读大量输出、逐条搬运数据，也未必节省多少资源。

Codex 对“操作电脑是错误方向”保留一个条件：如果应用没有可用的结构化入口，界面操作仍可能帮助完成原本无法委托的任务。它可以是兼容既有软件的手段，不必成为每个重复任务的长期执行路径。界面本身需要被检查、任务只发生一次，或者编写与维护自动化的成本更高时，也需要比较整个任务的收益。

一个相关工程例子是 Anthropic 的 [Code execution with MCP](https://www.anthropic.com/engineering/code-execution-with-mcp)：通过代码组合工具调用，在执行环境内过滤和处理数据，再把必要结果返回模型。这支持将确定性执行从反复推理中分离出来的方向，并非所有工作负载都能获得同样收益的证明。

接下来可以继续讨论：一个 Agent 是否应当随着经验增加，把更多稳定步骤转成程序，把推理集中到新的困难上？如果如此，衡量进步除了成功率与旧能力保留，也应观察重复任务的总耗时、计算开销和人的投入是否下降。

## 八、同日续谈：个人负担、自动化与财富分配

### Peter 的自我观察与尚未确定的想法

Peter 特别说明，这一段没有前面的观点那么确切，也可能带有为自己辩驳的成分。这种自我怀疑需要保留，不能把下面的想法整理成一套已经确定的理论。

他观察到，自己使用 token 并不节约，更关心一个人能够撬动多少资源来帮助自己做事；从老板或组织的视角看，更常见的问题可能是，消耗多少资源完成了多大工作。

两者的区别可能在时间，也在负担。他希望尽可能把事情完整交出去，追求各种 auto，最终能够坐享其成。他不希望一直参与全过程，再指挥 AI 指哪打哪。他所追求的收益包括解除个人负担。

沿着这个方向，他感觉做成某件事可能正在变得越来越不重要；知道要做什么，理解自己和大家想要什么，会变得更重要。他预期，随着 AI 继续发展，新手与熟练使用者之间的差距会缩小，AI 会更主动地询问、理解人的需要。

Peter 认为 Astra 在自己的使用体验中已经表现出这种趋势，并期待出现一系列善解人意的工具。这是他的体验与未来预期，本轮未将其改写成已验证的模型能力比较。

这些期待把讨论引向人的价值如何兑现，以及更现实的分配问题：假如 AI 能完成 99% 的工作，经济收益是否也会有 99% 集中到富人那里？这个比例是思想实验中的假设，不是当前自动化程度或未来财富份额的预测。

### Codex 的理解与补充

节省推理资源与追求充分委托，可以是不同层次的目标。个人愿意用更多计算换取更少的注意力投入，而 Agent 内部仍然可以用程序降低完成委托的成本。两者是否冲突，要比较实际换回了多少自由时间、监督是否真正减少、费用是否由承担者接受；不能仅凭 token 多或少判断。

这里还可以区分总耗时与人的在场时间。Agent 在后台运行很久，仍可能比要求人持续盯着的短任务更符合 Peter 的目的。但如果事后检查和补救更费力，负担就只是被推迟。

“知道想要什么更重要”可以理解为，当执行门槛下降时，选择目标与判断结果是否值得的相对作用上升。它不意味着实现和可靠性已经无关紧要，也不意味着每个人必须提出独特需求，才具有生活价值。

能力门槛下降与财富集中也可能同时发生。更多人能够借助 AI 完成工作，并不自动意味着他们能分享生产系统的所有权、利润或资源。若劳动收入下降，而资本、市场入口和关键资产的收益上升，使用能力变得普及仍可能伴随财富差距扩大。反过来，低成本的生产能力也可能降低个人或小团队进入市场的门槛；结果取决于实际竞争与分配条件。

“AI 做 99% 的工作”不能直接换算成某一群体获得 99% 的收入或财富。任务份额、劳动收入份额、利润与财富存量是不同的量。作为情景研究，[AI Adoption and Inequality（2025）](https://www.imf.org/-/media/Files/Publications/WP/2025/English/wpiea2025068-print-pdf.ashx)用家庭数据与经济模型分析工资和资本收益，发现工资差距缩小与财富差距扩大可能并存。这是模型中的条件性结果，不是已经实现的结局或必然预测。

如果劳动不再是大多数人获得收入的主要渠道，如何通过更广泛的资本所有权、公共服务或其他分配机制让人分享收益，就成为需要单独设计的问题。[Preparing for the (Non-Existent?) Future of Work](https://www.nber.org/papers/w30172)讨论了这种条件下劳动市场之外的收入分配路径。

本轮新留下的问题是：生产能力增强之后，普通人能否真正拥有更多可支配时间，并持续获得实现自己愿望所需的资源？这使个人对自动化的期待，与社会如何分配自动化收益连接起来。
