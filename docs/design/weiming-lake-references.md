# 未名湖像素湖景参考

## 构图

按 Peter 提供的对岸照片取景：博雅塔在左，花神庙的小红墙拱门在中部柳树间，远处屋顶只露少量；右侧衔接从对岸远看的湖心岛与石舫。为横幅布局做了位置与比例简化，并非地理测绘。

## 石舫

- 来源：[北京大学英文新闻网 — Shuchun Garden](https://newsen.pku.edu.cn/news_events/news/campus/9759.html)，2020-05-12，摄影署名 Lv Chen。
- [石材细节参考](https://newsen.pku.edu.cn/Uploads/Bden/File/2020/11/09/wk55ehm0xa2.jpg)：此图是在岛上近看石舫，用户明确指出不能用它的视角与对岸照片衔接。仅参考石材和船头细节。
- 对岸空间参考：本机 `Documents/pku-pixel-world-v5/reference-images/island-autumn-003.jpg`（原来源 Wikimedia Commons 未名湖分类）。画面显示完整树岛、石岸、右端近乎正面的低矮石舫和大片水面。采用这种远观尺度，平台仅露窄条，取消近景斜向平台。
- 提取特征：低矮船形石座、开放平坦铺石平台、向两侧翘起的船头石沿、侧面分层石材与浅浮雕、靠岛一端的短石柱。树丛与不规则石岸围绕后部。
- 照片仅用于观察轮廓，未复制到网站的公开资源中；网站仍使用 Canvas 原创几何绘制。
- 所有建筑、植被、湖水与终端配色均沿用北京时间的昼夜变化。
